## 1. 本次实际验证结果

统计范围为 v_sales_transactions 中 2011 年 11 月的交易明细，包含 11 月 1 日、不包含 12 月 1 日，要求客户编号存在。先按客户与商品统计不同发票数，保留至少两张发票的组合，再对客户编号去重计数。

| 核验项 | 结果 |
|---|---|
| 满足条件的客户与商品组合 | 4629 个 |
| 涉及的不同可识别客户 | 412 名 |
| 每个满足条件组合的不同发票数 | 最少 2，最多 12 |
| SQL 独立核对 | 先对客户、商品、发票去重，再分组计数，逐组结果一致 |
| pandas 与 SQL 对照 | 组合数 4629、人数 412，一致 |
| notebook 保存的执行顺序 | 六个代码单元依次为 1、2、3、4、5、6 |
| notebook 保存的执行错误 | 0 |

用户报告已重启内核后运行全部单元，保存的连续执行编号、读库输出和最终结果与此相符。因此本机环境下的顺序运行验证通过。该结论不等于已经在全新电脑上安装依赖并完成复现。

4629 是客户与商品的组合数，不是客户人数。同一客户可以因重复购买多种商品而占据多行。412 仅指在这个观察月份内、至少一种商品出现在两张不同发票中的可识别客户，不代表全部客户、跨期留存或客户生命周期复购率。
